# Orlong collectible card artwork

Upload the exported card-front PNG files into this folder.

Use the permanent card numbers in the filenames:

- `CHR-001-maya-garcia.png`
- `CHR-002-elena-strix.png`
- `CHR-003-mrs-finch.png`

Keep the Canva source designs separately so the artwork remains editable.

These files are intended to be public website artwork. Do not put private manuscript pages, unpublished chapter text, account information, or personal reader data in this folder.

Once the PNGs have been uploaded, the card catalogue's `artworkUrl` fields can be connected to their website paths:
- `/explore-eden/cards/CHR-001-maya-garcia.png`
- `/explore-eden/cards/CHR-002-elena-strix.png`
- `/explore-eden/cards/CHR-003-mrs-finch.png`

The card images are not required for the Stage 2 reward engine to work. The catalogue and reward records are stored separately from the artwork.
